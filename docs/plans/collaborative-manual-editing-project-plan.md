# Collaborative Manual Editing System

A simple way for our team to edit, translate, and print the sacred teaching manuals together — from any browser, no technical skills needed.

---

## The Manuals

Starting with four manuals (more can be added anytime):

- Rose Meditation Level 1
- Rose Meditation Level 2
- Rose Meditation Level 3
- Aura Level 1

---

## Languages

Each manual will be available in six languages. Editors can work on any language independently.

- English
- Portuguese
- Spanish
- Greek
- Russian *(new)*
- Ukrainian *(new)*

---

## Who Gets Access

Access is controlled by simple 4-digit PIN codes — no accounts or passwords to remember.

**Editors** (collaborators who update content)
- Edit text and headings in any manual
- Upload and swap images
- Rearrange, add, or remove sections
- Download finished manuals

**Teachers** (read-only access)
- View any manual in any language
- Download as PDF, Word, or Markdown for printing
- Cannot change content

An admin can change both PINs at any time from the dashboard.

---

## How Editing Works

The editor works like Notion — each manual is a stack of blocks you can click to edit, drag to rearrange, and "+" to add new ones. Changes save automatically.

**What you can add:**
- **Headings** — Section titles (large, medium, or small)
- **Text** — Paragraphs with basic formatting (bold, italic, lists)
- **Images** — Upload photos or illustrations with optional captions
- **Dividers** — Decorative lines between sections
- **Page Breaks** — Start a new page when printed

---

## Downloading & Printing

Anyone with a PIN can download a manual in three formats:

- **PDF** — Ready to print on US Letter paper (8.5" x 11") with proper layout, fonts, and images
- **Word (DOCX)** — For further editing in Word or Google Docs
- **Markdown** — Plain text backup

---

## What Editors Will See

1. Go to `/manuals` on the site
2. Enter your PIN
3. Choose a manual from the grid
4. Pick your language
5. Edit blocks in place — everything saves automatically
6. Download when ready

---

## Decisions Made

1. **Starting content** — Pull in existing manual text automatically so editors aren't starting from scratch.
2. **Translations** — Editors translate directly in the system. Pick a language, edit in place.
3. **Change awareness** — The system will show when someone has recently edited a manual (e.g. "Last edited by Editor 2, 10 minutes ago") so collaborators stay aware of each other's work.
