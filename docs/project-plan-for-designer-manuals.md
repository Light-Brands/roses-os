## 1. PURPOSE

The student manuals are personal companions for participants -- reference documents they keep after completing each level. Unlike the Teacher's Resource Manual (which is a facilitator's live-session tool), these manuals are for students to review, reflect, and deepen their understanding of the teachings.

**Goals:**

- Provide students with a beautifully designed personal reference for each level
- Update all imagery to match the creative direction established in the Teacher's Resource Manual
- Replace legacy 2022 manual designs with the elevated ROSES OS brand language
- Make manuals available in four languages for the global community
- Ensure every manual is downloadable as a high-quality PDF

## 4. CREATIVE DIRECTION -- ALIGNMENT WITH TEACHER'S RESOURCE MANUAL

The manuals must share the same visual DNA as the Teacher's Resource Manual (MDR). This means:

### Illustration Style
- Elegant line drawings with color that evokes watercolor -- a feeling of a time that came before
- Drawings should feel pure, innocent, vibrant, and loving
- Heritage context: honor the original stick-and-line style from the tradition's history while creating elevated, modern renditions
- **Rose depiction rule:** Roses are always depicted as a stem and a flower only -- never with thorns or leaves

### Imagery & Representation
- All figures must represent a wide variety of body shapes, sizes, nationalities, and ethnicities -- reflecting the whole world
- Both male and female figures throughout
- Figures should feel like elegant, timeless beings -- high-end ancient-meets-modern style
- The designer has creative freedom to create new, diverse examples -- not simply reuse Teacher's Resource Manual images

### Brand Palette Application
- Non-chakra pages use the warm neutral background palette (Rose Clay Mauve, Peach Sand, Golden Ether, Aura White)
- Chakra pages use each chakra's correct color as the dominant accent
- Gold accents (`#9E956B`) for headings, dividers, key phrases -- used intentionally, never decoratively
- Typography: Cormorant Garamond for headers, Inter for body text

### What's Different from the Teacher's Manual
- Student manuals include **more explanatory text** -- these are study references, not live-session visual aids
- Layout is optimized for **reading and reflection**, not live presentation
- Manuals may include **practice exercises, journaling prompts, or reflection spaces** if appropriate
- PDF is the primary format (not web-first like the Teacher's Manual)

## 5. MULTILINGUAL REQUIREMENTS

Each manual must be produced in **four languages:**

| Language | Code | Notes |
|----------|------|-------|
| English | EN | Primary language -- designed first |
| Spanish | ES | Full translation, not literal -- respect linguistic nuance |
| Portuguese | PT | Full translation, not literal -- respect linguistic nuance |
| Greek | EL | Full translation, not literal -- respect linguistic nuance |

**Production approach:**
- Design the English version first as the master layout
- Translate text content for each additional language
- Maintain identical layouts across all languages -- text-only swaps
- Adjust text blocks where necessary for languages that run longer or shorter
- Each language version is a separate, standalone PDF
- All four language versions must be available for download from the Resources section

**Total deliverables:** 3 manuals × 4 languages = **12 PDF documents**

---

## 6. PDF SPECIFICATIONS

All manuals follow the unified ROSES OS PDF template system:

- **Page size:** A4 / Letter (designed for both screen reading and print)
- **Typography:** Cormorant Garamond for headers, Inter for body -- matching the web and Teacher's Manual
- **Background:** Aura White (`#F7F5F2`) with subtle brand texture (clay, linen, or fogged light -- light enough to print cleanly)
- **Section headers and dividers:** Rose Clay Mauve (`#9C6F6E`)
- **Accent lines:** Antique Olive Brass (`#9E956B`)
- **Page elements:** Page numbers, section headers in footer, ROSES OS wordmark
- **Illustrations:** Must render cleanly in PDF (SVG or high-resolution PNG)
- **Access:** These are **not** password-protected (unlike the Teacher's Manual) -- they are student resources
- **File naming convention:** `ROSES-OS-Level-2-Manual-EN.pdf`, `ROSES-OS-Levels-1-2-Manual-ES.pdf`, `ROSES-OS-Level-3-2026-EL.pdf`, etc.

## 9. CREATIVE FREEDOM

The designer has creative freedom in executing these manuals. The imagery should match the Teacher's Resource Manual in style and spirit, but the student manuals are their own documents -- they may have their own visual rhythm, pacing, and moments of beauty. The designer should bring the same level of care and craft to these manuals as to the Teacher's Resource Manual. Where something isn't specified, follow the brand's tone -- warm, sacred, grounded, quiet.
