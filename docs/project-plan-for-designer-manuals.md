## 1. PURPOSE

The student manuals are personal companions for participants -- reference documents they keep after completing each level. Unlike the Teacher's Resource Manual (which is a facilitator's live-session tool), these manuals are for students to review, reflect, and deepen their understanding of the teachings.

**Why only Level 2 and Level 3:**
- Level 1 content is already covered in the existing Level 1 manual -- no need to duplicate it
- The Level 2 manual is a standalone document for Level 2 content only (not combined with Level 1)
- Level 3 is updated as the 2026 edition

**Goals:**

- Reimagine all level imagery with figures in Greek-style clothing (Yeva World / Caravana aesthetic)
- Pull imagery from the Teacher's Resource Manual where appropriate, or create new illustrations
- **Always maintain accuracy** -- every illustration must faithfully depict the teaching position or imagination technique it represents
- Make manuals available in four languages for the global community
- Deliver before March 15 class start date

## 4. CREATIVE DIRECTION -- THE REIMAGINED IMAGE STYLE

### The Aesthetic: Greek-Meets-Modern

All figures in the manuals should be depicted wearing **Greek-style clothing in the Yeva World / Caravana aesthetic** -- high-end ancient-meets-modern style with natural materials like linen, silk, and raw natural fibers in neutral tones. This is the same fashion and figure direction established in the brand DNA and Teacher's Resource Manual.

**Key references:**
- [Caravana](https://caravana.land) -- artisan-driven luxury resort wear
- [Yeva World](https://yeva.world) -- design inspiration
- High-end Greek fashion that blends ancient heritage with modern minimalism -- designers like Zeus+Dione, Celia Dragouni, Vassilis Zoulias; brands like Greek Archaic Kori, Pearl and Caviar, Parthenis -- the sophisticated Aegean aesthetic

### Image Sourcing

Images can come from two sources:

1. **Pulled from the Teacher's Resource Manual** -- reuse or adapt illustrations already created for the MDR where they fit the student manual context
2. **Created new** -- where the Teacher's Resource Manual doesn't have what's needed, create new illustrations in the same style

**The non-negotiable rule:** Every illustration must **accurately depict the teaching position or imagination technique** it represents. The creative reimagining is about the aesthetic wrapper (clothing, style, setting) -- not about changing what is being taught. The grounding cord must still look like a grounding cord. The golden sun must still be clearly recognizable. Chakra placements must be anatomically correct. The beauty serves the teaching, never the other way around.

### Illustration Style
- Elegant line drawings with color that evokes watercolor -- a feeling of a time that came before
- Drawings should feel pure, innocent, vibrant, and loving
- Figures dressed in Greek-style / Yeva World / Caravana clothing -- linen, silk, raw natural fibers, neutral tones
- Heritage context: honor the original stick-and-line style from the tradition's history while creating elevated, modern renditions
- **Rose depiction rule:** Roses are always depicted as a stem and a flower only -- never with thorns or leaves

### Imagery & Representation
- All figures must represent a wide variety of body shapes, sizes, nationalities, and ethnicities -- reflecting the whole world, like the United Nations
- Both male and female figures throughout
- No single type of person should dominate the imagery
- Figures should feel like elegant, timeless beings in their Greek-inspired attire

### Brand Palette Application
- Non-chakra pages use the warm neutral background palette (Rose Clay Mauve, Peach Sand, Golden Ether, Aura White)
- Chakra pages use each chakra's correct color as the dominant accent
- Gold accents (`#9E956B`) for headings, dividers, key phrases -- used intentionally, never decoratively
- Typography: Cormorant Garamond for headers, Inter for body text

### What's Different from the Teacher's Manual
- Student manuals include **more explanatory text** -- these are study references, not live-session visual aids
- Layout is optimized for **reading and reflection**, not live presentation
- Manuals may include **practice exercises, journaling prompts, or reflection spaces** if appropriate
- PDF is the primary format (not web-first like the Teacher's Manual)

## 5. MULTILINGUAL REQUIREMENTS

Each manual must be produced in **four languages:**

| Language | Code | Notes |
|----------|------|-------|
| English | EN | Primary language -- designed first |
| Spanish | ES | Full translation, not literal -- respect linguistic nuance |
| Portuguese | PT | Full translation, not literal -- respect linguistic nuance |
| Greek | EL | Full translation, not literal -- respect linguistic nuance |

**Production approach:**
- Design the English version first as the master layout
- Translate text content for each additional language
- Maintain identical layouts across all languages -- text-only swaps
- Adjust text blocks where necessary for languages that run longer or shorter
- Each language version is a separate, standalone PDF
- All four language versions must be available for download from the Resources section

**Total deliverables:** 2 manuals × 4 languages = **8 PDF documents**

## 6. PDF SPECIFICATIONS

All manuals follow the unified ROSES OS PDF template system:

- **Page size:** A4 / Letter (designed for both screen reading and print)
- **Typography:** Cormorant Garamond for headers, Inter for body -- matching the web and Teacher's Manual
- **Background:** Aura White (`#F7F5F2`) with subtle brand texture (clay, linen, or fogged light -- light enough to print cleanly)
- **Section headers and dividers:** Rose Clay Mauve (`#9C6F6E`)
- **Accent lines:** Antique Olive Brass (`#9E956B`)
- **Page elements:** Page numbers, section headers in footer, ROSES OS wordmark
- **Illustrations:** Must render cleanly in PDF (SVG or high-resolution PNG)
- **Access:** These are **not** password-protected (unlike the Teacher's Manual) -- they are student resources
- **File naming convention:** `ROSES-OS-Level-2-Manual-EN.pdf`, `ROSES-OS-Level-2-Manual-ES.pdf`, `ROSES-OS-Level-3-2026-EN.pdf`, `ROSES-OS-Level-3-2026-EL.pdf`, etc.

## 9. CREATIVE FREEDOM

The designer has creative freedom in executing these manuals. The reimagined Greek-style / Yeva World / Caravana aesthetic should feel natural and beautiful -- but **accuracy of the teaching depiction is always the priority**. Every illustration must faithfully show the meditation position, energetic structure, or imagination technique being taught. Within that constraint, the designer should bring their full creative vision -- the clothing, the settings, the color treatment, the composition are all open to interpretation. Where something isn't specified, follow the brand's tone -- warm, sacred, grounded, quiet.

Given the tight timeline, the designer should work efficiently -- reusing and adapting Teacher's Resource Manual imagery where possible, creating new only where needed. Speed matters, but the brand standard must hold.
