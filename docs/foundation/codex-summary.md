# Roses OS Codex -- Summary

> A concise reference summarizing the full ecosystem: philosophy, lineage, platform, design system, and documentation.

---

## What ROSES OS Is

ROSES OS is a full-stack spiritual technology platform -- part web application, part philosophical knowledge base, part educational ecosystem. It combines a modern Next.js web platform with a deep body of teachings around consciousness, coherence, and what it calls "Technologies of Remembrance."

---

## Core Philosophy

**The Rose** is the central concept -- a "living inner technology of remembrance" that:

- Restores coherence across emotional, mental, and energetic systems
- Makes intuition precise and presence sovereign
- Is explicitly not a belief system -- it is framed as honest awareness and presence

**The Aura** sharpens perception, revealing what shapes choices, relationships, and reality. It empowers leadership through energy reading.

**Coherence** is the foundational principle: inner agreement where mind, heart, words, and truth move in the same direction.

### The Two Questions

1. Are you aware of your inner state at this moment?
2. Do you feel coherent inside -- if not, how can you restore it?

## Platform Structure

The web application is built with **Next.js 16, TypeScript, React 19, Tailwind CSS, and Three.js**.

| Section | Purpose |
|---------|---------|
| **Public site** | Homepage, The Rose, Programs, Guardians, Offerings, Community, Contact |
| **Invitation flow** | Welcome and learn-more pages with contribution tiers |
| **Forms** | Enrollment, contribution, and agreements |
| **Teaching hub** | Password-protected Levels 1--3 content |
| **Admin dashboard** | Analytics, content management, users, media, settings |

### Notable Features

- Interactive **3D rose model** (Three.js / React Three Fiber)
- Page transitions and subtle animations (Framer Motion, GSAP)
- Chakra color system for teaching visualizations
- PWA support
- Dark/light theme switching
- AI-first development infrastructure (Claude Code hooks, subagents, skill commands)

## Design System

The visual identity follows a **"sacred-tech minimalism"** aesthetic.

**Colors** -- Warm palette with no cold greys:

- Aura White (`#F7F5F2`), Cream Veil (`#FFF8E7`)
- Rose Clay Mauve (`#9C6F6E`) -- the signature color
- Antique Olive Brass (`#9E956B`) -- rare accent, like gold in a temple

**Typography:**

- **Display:** Cormorant Garamond (sacred, devotional)
- **Body:** Inter (modern, clean)

**Principles:**

- Breathing minimalism with generous whitespace
- Typography-first hierarchy
- Subtle motion (fade + translate)
- Progressive disclosure
- Warm restraint
